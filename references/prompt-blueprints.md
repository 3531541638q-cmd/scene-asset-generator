# 场景主图提示词骨架

这是组织信息的骨架，不是每次照抄的固定长提示词。用户的具体要求优先。实际出图前，有参考图时先问同机位或新机位，并按主技能确认呈现方式与陈设；单独写提示词可先标明待定条件。先交付一张主图，不排多格；完成后询问是否生成多机位九视图，确认后再扩展。

## 照片输入的两段提示词

### 照片反推提示词

独立描述照片可见的场景类型、用途、结构比例、门窗与通道、主要陈设或景物、材质、配色、使用状态、机位、光线与时间天气。不猜真实地址，不把画外结构或精确尺寸写成事实。照片有遮挡时直接说明观察边界。

这一段先在对话中展示。照片里的路人、摄影者倒影、水印或无关品牌，不自动转成新图的保留要求。

### 实际场景生成提示词

- **原创模式**：以反推描述为基础，明确“依据以下文字创作另一处原创场景”，设计两三个相容的结构特点，保留用户指定的风格与陈设；不附原照片，不写原址复刻或其他锁定原空间的要求。
- **保留原场景模式**：明确原照片是结构依据，列出必须保留的门窗、墙体、固定设施、家具或构图，再列唯一要改的部分。使用参考图参数前实际查看原图，避免把陈设风格图错当原场景依据。
- **同机位模式**：用户选择后，用其指定的原图作构图和透视依据，锁定镜头位置、观看高度、朝向、取景距离、原横竖画幅与画面边界，再列去人、去叠字或换陈设等允许修改项。不是先按纯文字新造房型再尝试凑同一机位；也不拿已偏离机位的生成图替代原参考。

分别保存两段实际文字。反推描述不等于已出图，原创示例不等于用户认可案例。

## 主图信息顺序

1. **交付**：一张独立场景摄影主图，场景类型与用途，横竖画幅；不拼版。
2. **场景与机位模式**：列同机位或新机位、文字原创或保留原场景，以及用户锁定内容；机位选择与是否重设计场景分别说明。
3. **空间结构**：主要开间与进深关系、开口位置、层次或地形，选两三个能相容的辨识点。明确家具与门窗的空间关系，避免只写画面左边右边而忽略物体所在位置。
4. **陈设与活动空间**：主要家具、产品、植被或设施的样式、材质、相对尺度及必要空位，按陈设选择执行。不堆无关小物，不自动加人物。
5. **真实状态**：具体材料的受光差别、符合用途的少量使用痕迹，或新空间合理的工艺与摆放状态。
6. **呈现方式**：本次确认的完整环境或白底独立布景，说明主体边界与保留部分。
7. **机位与光线**：观察方向、视点高度、景别、主要空间占比、前中后景、裁切边界、光源方向与时间天气。先保证结构可读，再安排气氛。
8. **关键约束**：只列最相关的几项，例如不改门窗、无意外人物、无畸形透视、无多格、无额外文字。不用长串抽象否定词代替正面设计。

## 呈现方式模块

### 同机位条件

用户选同机位时，提示词先锁定原图的镜头位置、朝向、观看高度、取景距离、透视、画幅与裁切；之后才描述修改。强调保留已见结构及物件在画面中的相对位置，去人或去叠字后按现有线条补全。禁止后退、扩宽、换侧向全景或为了展示更多空间改成横版。与白底同时选择时，只处理指定主体之外的外围，机位仍保持。

### 完整环境

只在用户确认保留完整环境后加入：保留构成场景的墙地、天花、建筑、天空或周边环境；画面是一张可直接使用的真实场景照片。不要移到白色摄影棚，也不要为了全景把不可能同时看见的墙面硬拼进画面。

### 白底独立布景

只在用户确认白底独立布景后加入：明确保留哪一块场景本体及其必要的地面、墙体、家具或植物；外围为纯白。布景自身保留原材料、色彩、体积、真实尺度与自然接触阴影，不微缩、不做沙盘、不默认改成剖切或轴测。陈设与指定文字仍保留，原远景不漏回外围。

完整封闭空间若不能在不改变结构的情况下满足白底呈现，不擅自拆墙。先确定要作为独立布景保留的范围；用户明确选择开放布景时，再据此设计边界。

## 按用途选择构图

- **室内空间主图**：把主要墙面、地面和核心陈设组织成可读的纵深，让门窗与家具位置成立。自然视点不等于必须四面墙全入镜，也不默认超广角。
- **室外空间主图**：先确定主要道路、建筑或地形，再安排前中后景与远景份量。天空和装饰性前景不应挤掉核心空间。
- **人物合成或视频背景**：按将要发生的动作留下可使用的位置、地面和景深；只做背景时不生成人物，不额外设计剧情或镜头序列。
- **指定产品所在场景**：产品依据权威参考保持结构、比例与材质，围绕其真实摆放和使用关系组织空间，不用泛化近似品替换。

## 针对反馈的修订

| 反馈 | 优先检查与修正 |
| --- | --- |
| 像建模、太像样板间 | 先核对空间比例、门窗与家具使用关系，再改材质、光线和少量使用状态；不靠加脏或加噪点解决。 |
| 没有特点、都像同一间房 | 在用户未锁定的范围内重设计两三个相容的结构关系，不只换软装颜色。 |
| 场景不够完整 | 根据表达目标调整机位与取景边界；不自动退到远处或拉成超广角。 |
| 空间太空、主体太小 | 收紧无效天空、空地或装饰前景，让主要结构和陈设占据足够面积。 |
| 材质不真实 | 保留已确定的结构和构图，按具体材料分别修正纹理、粗糙度、反光与接缝。 |
| 家具或产品变了 | 对照用户指定参考只修该物件，保留其余空间与光线，不整间重设计。 |
| 原图结构被改 | 回到保留原场景模式，列明可见固定结构与允许修改范围，用原图作结构依据。 |
| 机位偏了、要同机位 | 回到用户指定的原图做参考，锁定画幅、透视、墙框与地面等对照位置，只修获准内容；不继续以已偏离的生成图为构图依据。 |
| 白底后场景消失或变成模型 | 重申场景本体、必要地墙与真实尺度，只处理外围，不把白底变成删主体或微缩。 |

用户对某一张图的反馈不自动升级成所有场景的长期默认。仅在“存档”或直接要求修改技能时更新本技能。

## 主图之后的可选九视图

主图完成后先询问用户，或依用户已有的九视图指令执行。九视图使用本次选定主图作为结构参考，沿用同一空间与呈现方式，不再次随机创作新场景。按 [九视图与编号提取](multiview-nine.md) 固定布局、设计九个相机、排3×3并编号01–09；九宫格完成后等用户选编号，再提取对应单图。
