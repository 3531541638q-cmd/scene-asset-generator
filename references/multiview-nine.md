# 同场景九视图与编号提取

用户确认需要九视图，或已经直接提出该要求时，读取本文件。主图仍先独立交付，不把九宫格当作默认首张图。

## 固定布局，再设计机位

从选定主图标出三个或更多可持续核对的结构关系：开口与墙柱、家具与通道、地面交界、固定灯具等。描述相对位置即可，不把估算写成测量尺寸。将主图看向的一侧定义为A，右侧B，相机后方C，左侧D；这些只是本次设计坐标。面向A时B在画面右、D在左，转向C时B在左、D在右。物体的空间位置不随画面左右改变。

先判断场景是否允许机位移动。相机不能穿墙、钻进柜体、越过无法到达的障碍或透视屋顶；小空间可选不同高度或沿实际通道布置。白底独立布景只展示同一结构的不同可拍方向，不擅自补成封闭房屋。画外信息只作必要且相容的设计补全，不能说成真实原址信息。

九个机位的常用起点如下，按场景可拍性调整，不机械照抄方位：

| 编号 | 相机安排 | 核对重点 |
| --- | --- | --- |
| 01 | 接近主图的基准全景 | 让用户与主图对照已知结构。 |
| 02 | 主图机位左移后的斜向视图 | 应有真实横移产生的遮挡和透视变化。 |
| 03 | 主图机位右移后的斜向视图 | 与02的固定物件位置能互相印证。 |
| 04 | 从左侧向右横拍 | 主图前后结构应落在对应的左右边缘。 |
| 05 | 从右侧向左横拍 | 与04方向相反，不能变成另一张反向全景。 |
| 06 | 从主图看向的一侧反拍 | 左右关系正确交换，画外补全克制。 |
| 07 | 左后侧对角位置斜拍 | 用前景结构与地面交界交代相机位置。 |
| 08 | 右后侧对角位置斜拍 | 与07属于同一空间，不能搬动家具凑构图。 |
| 09 | 较高或较低的整体关系视图 | 高度可实际达到，不穿透建筑；避免仅重复01。 |

每格都应是可独立使用的场景照片，而非局部材质特写。无需强迫所有物件每格可见；允许正确遮挡与画外内容，更不能为了重复标志物把它们挪到镜头前。

## 九宫格提示词的内容

1. 明确3×3九格与01–09编号顺序、每格画幅、窄分隔线、小编号位置，保留后续单格提取所需的主体边界。
2. 标明主图是结构权威，其他已检查角度只补充空间，不引入不同场景或更换装修。
3. 写清唯一布局、固定物件和相对方向，再逐格描述相机位置、朝向、观看高度和应看见的结构关系。
4. 锁定材质、陈设、时间与光向；仅改变机位和正常透视。避免用“角度都不同”替代具体相机安排。
5. 区分已知结构与最少的画外设计补全。不复制某次案例的房型、木梁、帘布或家具到新场景。

## 看图检查

- 逐格数清01–09，核对确有九个视图、分隔线清楚、编号未遮主体。
- 按正反、左右、对角三组比对固定结构的位置、侧别和相互连接；检查门窗是否凭空换墙、家具是否搬动或复制、地面纹路和交界是否重排。
- 检查反打中左右交换是否正确，画外补全能否与主图相接，镜面中是否出现不相容空间。
- 比较相近格，排除重复裁切、镜像或朝向几乎相同的机位。若某格偏离布局，只修该格并复查邻格，不无理由重抽整板。
- 检查真实像素后才描述结果；不能把图像生成的空间一致性说成几何标定或精确三维重建。

## 选编号后提取

以用户选中的那一版九宫格为唯一取图依据。单个编号对应一张图，多个编号按用户顺序分别交付；不额外重生成其他机位。

先核对格子实际边界，再提取内容；去掉相邻格、分隔线和角标时不吞掉主体。保留原始九宫格，文件名标明所属场景、九宫格版本和编号。遵守当前图像工具规则；像素裁切、插值放大、生成式重绘分别如实说明，不把重绘当作原图无损提取，不把总图尺寸当成单格尺寸。画面不够清晰或用户要高清单图时，以选中格为构图依据处理，不擅改空间结构。
